# KidFund

Учёт капитала ребёнка с рождения до 18 лет: подарки, пособия, материнский капитал, покупки активов, займы родителей, прогноз и цели.

**Открыть:** https://ragim89.github.io/kidfund/

## Установка на iPhone
1. Откройте ссылку в Safari.
2. «Поделиться» → «На экран „Домой“» → «Добавить».

## Установка на Android
Откройте ссылку в Chrome → меню ⋮ → «Установить приложение».

Данные хранятся только на телефоне пользователя. Курсы валют — ЦБ РФ (cbr-xml-daily.ru), обновляются автоматически.

## Файлы
- `index.html` — всё приложение
- `manifest.webmanifest` — описание приложения для установки
- `sw.js` — офлайн-режим
- `icons/` — значки
